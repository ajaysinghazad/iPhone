Corey Patient — White Label User Flow

First launch selects organisation; subsequent launches restore saved branding and skip selection.

App launch
↓
Saved organisation on device?
No — first launch
↓
Select / search organisation
↓
Match code → fetch OrgTheme (API)
↓
Persist orgId + theme cache (Keychain / UserDefaults)
Yes — return launch
↓
Load saved org + theme
↓
Optional: refresh theme if stale
↓
Branded login (username + password only)
↓
Authenticate → Dashboard (themed navbar, accents, crisis button)
↓
User taps Change organisation?
↓
Clear session · show Select Organisation · apply new theme
OrgTheme fields: primaryColor, secondaryColor, accentColor, loginWallpaperURL, logoURL, appDisplayName, navbarStyle
Entry points for change: Login screen shortcut, Profile & Settings → Change organisation
